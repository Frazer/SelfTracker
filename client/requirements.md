## Packages
recharts | For visualizing history (bar charts and line charts)
date-fns | For date manipulation and formatting
framer-motion | For smooth animations and transitions
lucide-react | For icons
clsx | For conditional class names
tailwind-merge | For merging tailwind classes

## Notes
Data persistence is handled via localStorage (no backend).
Using a custom hook `useLocalStorage` to manage state.
Theme: Clean, minimal, sophisticated with subtle gradients and shadows.
